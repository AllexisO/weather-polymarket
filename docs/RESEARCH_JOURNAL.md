## 20.10 — почему LLM-кошельки хуже рынка (llm_hour_preds 03-20.10, ~6 500 прогнозов)
По часам LLM хуже рынка на 0.06-0.16 в каждый час. 2-3% прогнозов, где LLM дала выигравшему < 5%, а рынок ≥ 10%, дают 56-100%
всего отставания. Страховка «шанс ≥ 0.5 × цена рынка» сокращает отставание примерно вдвое (08 ч 0.969 → 0.884, рынок 0.817; 16 ч
0.271 = рынок). Вечером (17-19 ч) LLM слишком осторожна: в среднем 91-92% на выигравший против 97-98% у рынка — разброс кода
±0.7° один на все часы. Остаток отставания утром (~0.07) — информация, которой у LLM нет. Страховка — заметка #96 (01.11).
Проверка 20.10 (`data/research/llm_sigma_check.py`, walk-forward, llm_agy + nomem, 1 878 прогнозов, сверка с живыми шансами ≤ 0.037):
разброс по каждому часу вместо блоков AGY_BLOCKS — хуже (08-13 ч 0.922 против 0.861), устойчивый разброс (MAD) — хуже утром
(1.151), вечером так же (0.316 / 0.319). **Не прошло.** Вечером число LLM верно в 97% (5 раз ждала рост выше измеренного —
все 5 сбылись); отставание вечером — от редких промахов, по которым разброс не настроить. Страховка 0.5 × рынок улучшает во всех
блоках (0.861 → 0.814, 0.631 → 0.555, 0.319 → 0.236), рынок (0.753 / 0.489 / 0.129) не догоняет.
