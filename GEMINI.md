# weather-lab — правила для Gemini (вид сайта)

Проект: бумажная торговля на погодных маркетах Polymarket, сайт на localhost:8093 (FastAPI + шаблоны Jinja).
Владелец — Alex. Работа поделена (решение Alex 09.10.2026):

- **Gemini — только вид сайта**: стили, расположение блоков, цвета, подписи, отступы, мобильная версия.
- **Claude — логика**: расчёты, модели, кошельки, ставки, скрипты, данные для страниц (`app/dashboard.py`).

## Что можно менять

- `app/templates/*.html` — разметка, CSS внутри `<style>`, порядок блоков, тексты подписей.
- `docs/DESIGN_SYSTEM.md` — если добавил новый общий приём оформления, допиши его сюда.

## Что НЕЛЬЗЯ менять

- Любые `.py` файлы (`app/dashboard.py`, `app/weather_*.py` и остальные), `check.sh`, `docker-compose.yml`, crontab.
- `.env` — не открывать и не печатать: там ключи.
- Папку `data/` (базы, модели, логи).
- **Числа и расчёты в шаблонах.** Шаблон показывает то, что даёт `dashboard.py`. Не пересчитывать, не придумывать данные,
  не менять смысл чисел и порогов (пороги записаны заранее в `docs/PRD.md`).
- Если для правки нужны новые данные на странице (новое число, новый график, новая колонка) — **не делать**: напиши Alex,
  что нужно, это задача для Claude.

## Как писать

- Тексты — по-русски, простым языком, без жаргона. Подпись объясняет, что значит число.
- Перед правкой прочитай `docs/DESIGN_SYSTEM.md`: тёмная палитра «Графит и пастель», шрифт Onest, цвета — только из
  переменных (`--bk-*` в наборе bk, `--bg`/`--panel`/… в `base.html`). Жёстко прописанные цвета — только внутри SVG-графиков.
- Сайт должен работать на телефоне: без горизонтальной прокрутки страницы, широкие таблицы — в обёртке с `overflow-x: auto`.
- Комментарий о причине правки — коротко в `{# … #}` рядом, в стиле существующих: `{# 09.10 (просьба Alex): … #}`.
- Общие куски: `_progress.html` (график «учится ли»), `_mm_style.html`, `_icons.html` — правка в них меняет несколько страниц сразу.

## ОБЯЗАТЕЛЬНО после каждой правки

```
./check.sh
```

Не заканчивать, пока в конце не будет **«ПРОВЕРКА ПРОЙДЕНА»**. Скрипт перезапускает сайт и открывает все страницы;
без перезапуска изменения шаблонов на сайте могут быть не видны.
Если проверка не проходит из-за твоей правки — исправь. Если из-за чего-то другого — не чини Python, напиши Alex.
