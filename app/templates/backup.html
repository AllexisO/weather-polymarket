Как восстановить

  1. Остановить крон проекта (закомментировать строки weather-lab в crontab -e) и сайт: sudo docker compose stop.
  2. Выбрать папку копии (таблица выше) и распаковать нужную базу: zstd -d "<папка>/polymarket_lab.sqlite3.zst" -o data/db/polymarket_lab.sqlite3 (так же остальные .zst; стаканы — books.sqlite3.zst → data/books/books.sqlite3).
  3. Исследования (скрипты и итоги): zstd -dc "<папка>/research.tar.zst" | tar -C data -xf -.
  4. Ключи API, если пропал .env: cp "<папка>/env.backup" .env.
  5. Проверить базу: sqlite3 data/db/polymarket_lab.sqlite3 "PRAGMA quick_check" → ok; запустить ./check.sh.
  6. Вернуть крон и сайт: sudo docker compose up -d. Код — из GitHub, модели переобучатся ночью.
